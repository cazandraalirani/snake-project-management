# Snake Game: Project Management Case

A 10-week team project (autumn 2023, University of Gothenburg / Chalmers) where a group of six students built a 2D Snake game in Java/JavaFX while practising project management with the OpenUP framework (Inception, Elaboration, Construction, Transition).

This repository shows the **project management artefacts**, not the game code.

## What the project produced
- A working Snake game with main menu, obstacles, sound and high-score storage
- Ten iterations with planning, review and retrospective meetings

## Artefacts in this repository

## Key lessons learned
- Detailed up-front plans (WBS, Gantt) were less useful than iteration-level planning once the work started.
- Too many tracking tools (Kanban board plus spreadsheet plus Gantt) meant none were kept up to date; one central spreadsheet worked best.
- Early time estimates were far too optimistic; reviewing estimates against actuals each iteration improved them.
- Asking for help early and assigning more people to hard tasks sped up progress.
- Team communication and meeting structure improved a lot once roles and agendas were defined.
